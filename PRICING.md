# Clicky Pricing Strategy

## 3-Tier System

### 🆓 **Free Plan** - $0/month
**Target**: Hobbyists, beginners, testing the platform

**Features**:
- 1 active profile
- Unlimited links/modules
- 5 module types (Link, Header, Text, Image, Divider)
- Basic analytics (views & clicks)
- Clicky branding footer
- Public profile page
- Mobile responsive
- SSL/HTTPS included

**Limitations**:
- No custom domain
- Basic module set only
- Clicky branding required
- Analytics limited to 30 days
- No priority support

---

### ⭐ **Pro Plan** - $9/month or $90/year (Save $18)
**Target**: Creators, influencers, small businesses

**Features**:
- **Everything in Free**, plus:
- 3 active profiles
- All 17+ module types unlocked:
  - Social Links
  - Video/Music embeds
  - Email Signup
  - File Downloads
  - Spacer controls
  - Custom HTML/CSS
- Advanced analytics (90 days):
  - Click-through rates
  - Top performing links
  - Device breakdown
  - Referrer tracking
- Remove Clicky branding
- Custom subdomain (yourname.clicky.site)
- 5 theme variations
- Priority email support
- Export analytics data

**Best For**: Content creators monetizing their audience

---

### 💎 **Business Plan** - $29/month or $290/year (Save $58)
**Target**: Agencies, businesses, power users

**Features**:
- **Everything in Pro**, plus:
- Unlimited profiles
- Custom domain support (yourdomain.com)
- Advanced modules:
  - Payment buttons (Stripe/PayPal)
  - Booking calendar integration
  - Contact forms with email
  - Product showcases
  - Button grids
  - Two-column layouts
  - Location/maps
- Full analytics (unlimited history):
  - Geographic data
  - Time-based trends
  - A/B testing
  - UTM tracking
  - API access
- White-label option
- Custom CSS/branding
- Team collaboration (3 seats)
- Priority chat support
- SLA guarantee
- Advanced security features

**Best For**: Agencies managing multiple clients, e-commerce businesses
